设计理念 ​

Syncraft Launcher 是一个专门服务于腐竹和服务器玩家的 Minecraft 服务器。如果你需要这篇文档，那么：

  • 你可能是一名腐竹，认为这个项目可以帮到你和你的服务器成员。
  • 你可能是一名玩家，你的腐竹叫你使用一个冷门启动器，你决定搜一搜。

如果你只是偶然路过的一名单机玩家，本项目似乎对你没有什么价值……

心理预期 ​

Syncraft 客户端对系统没有要求，但服务端目前仅支持 unix 系统。

Syncraft 假设它的使用者（特别是使用它的腐竹们）对于计算机和程序运作拥有一定的知识。比如，如果你对 Git 拥有一定理解，并能熟练修改各种配置文件，那么你应该能轻松驾驭本项目。

Syncraft 的服务端没有 GUI。甚至目前连客户端也没有 GUI。它有的只是一个拥有还算美观的输出的终端交互器。
