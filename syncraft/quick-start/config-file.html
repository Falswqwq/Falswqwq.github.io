配置文件 ​

服务端 (syncraft.toml) ​

置于服务端目录根下，syncraft serve 启动时读取。

toml
[info]
name = "我的服务器"
vanilla_version = "1.21.1"

[info.loader.Fabric]
loader_version = "0.16.10"

[network]
host = "127.0.0.1"
port = 3000

[[sync]]
path = "mods/"
to = "mods/"
mode = "Strict"

[[sync]]
path = "config/"
to = "config/"

[yggdrasil]
base_url = "http://example.com/yggdrasil"
skin_domains = ["example.com", "littleskin.cn"]
identity_falsification = false

[yggdrasil.email]
smtp_host = "smtp.example.com"
smtp_port = 587
username = "noreply@example.com"
password = "your_password"
from_name = "服务器验证"
字段类型说明
info.namestring服务器名称
info.vanilla_versionstringMinecraft 原版版本
info.loaderenum加载器类型：Vanilla、Fabric { loader_version }、Forge { loader_version }、NeoForge { loader_version }
network.hoststring绑定地址
network.portu16绑定端口
sync[].pathpath服务端内需要同步的文件/目录路径
sync[].topath客户端对应存储路径
sync[].modeenum同步模式：Strict（严格，默认）、Default（普通）、Forbidden（禁止客户端存在）
yggdrasil.base_urlstringYggdrasil 验证服务公开地址
yggdrasil.skin_domainsstring[]允许的皮肤域名白名单
yggdrasil.identity_falsificationbool是否允许伪造身份验证
yggdrasil.emailobject可选，SMTP 邮箱配置，用于注册验证

服务端包装器 (mswrapper.toml) ​

置于服务端目录根下，mswrapper 启动时读取。不存在时自动进入交互式创建流程。

toml
java_path = "/usr/lib/jvm/java-21-openjdk-amd64/bin/java"
host = "127.0.0.1"
port = 3022
字段类型说明
java_pathpathJava 可执行文件路径
hoststringHTTP 服务绑定地址
portu16HTTP 服务绑定端口

客户端启动器配置 (JSON) ​

由启动器自动管理，位于 launcher 目录下。

json
{
  "game_dir": ".minecraft",
  "java_paths": {
    "21": "/usr/lib/jvm/java-21-openjdk-amd64/bin/java",
    "17": "/usr/lib/jvm/java-17-openjdk-amd64/bin/java"
  },
  "selected_source": "BMCLAPI"
}
字段类型说明
game_dirstringMinecraft 游戏目录
java_pathsmapJava 大版本号 → 路径 映射
selected_sourceenum下载源：Default（Mojang 官方）或 BMCLAPI（镜像）

客户端状态 (.client.json) ​

位于游戏目录下，由启动器自动维护，记录同步状态与登录信息。

json
{
  "syncraft_link": "http://127.0.0.1:3000",
  "java": {
    "path": "/usr/lib/jvm/java-21-openjdk-amd64/bin/java",
    "version": 21
  },
  "version_hash": "c30debf1...",
  "account": {
    "Syncraft": {
      "username": "Falsw",
      "uuid": "abfd8ac566d64517baeda930f7aca91a",
      "email": "2538523045@qq.com",
      "client_token": "e246dc3219d6489a91c33e270d194c08",
      "access_token": "c4288e51de7e4053bf638b81a521d196"
    }
  },
  "skin_hash": null
}
字段类型说明
syncraft_linkstringSyncraft 服务端地址
javaobject选用的 Java 运行时路径与版本
version_hashstring当前已同步的版本哈希
accountenum登录账户：Offline { username, uuid } 或 Syncraft { ... }
skin_hashstring皮肤纹理哈希，用于缓存判断
