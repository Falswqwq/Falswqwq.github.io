配置文件 ​

syncraft.toml ​

位于你的 Minecraft 服务器根目录下，syncraft serve 启动时读取。

toml
[info]
name = "MyServer"
vanilla_version = "1.21.1"

[info.loader.Fabric]
loader_version = "0.16.10"

[network]
host = "127.0.0.1"
port = 3000

[[sync]]
path = "mods/"
to = "mods/"
mode = "Strict"

[yggdrasil]
base_url = "http://example.com/yggdrasil"
skin_domains = ["example.com", "littleskin.cn"]
identity_falsification = false

[yggdrasil.email]
smtp_host = "smtp.example.com"
smtp_port = 587
username = "noreply@example.com"
password = "your_password"
from_name = "QWQ"

游戏版本信息 ​

字段类型说明
info.namestring服务器名称
info.vanilla_versionstringMinecraft 版本
info.loaderenum加载器类型及版本

Minecraft版本、加载器类型及版本通常能被 syncraft-server 自主推断出来。

支持下面的加载器：

  • Vanilla：原版服务器/插件端服务器
  • Fabric { loader_version }：Fabric 加载器。
  • Forge { loader_version }：Forge 加载器。
  • NeoForge { loader_version }：NeoForge 加载器。

syncraft 网络配置 ​

字段类型说明
network.hoststring绑定地址
network.portu16绑定端口

同步文件配置 ​

字段类型说明
sync[].sourcepath服务端内需要同步的文件/目录路径
sync[].targetpath客户端对应存储路径
sync[].modeenum同步模式

见：文件同步。

Yggdrasil 配置 ​

字段类型说明
yggdrasil.base_urlstringYggdrasil 验证服务公开地址
yggdrasil.skin_domainsstring[]允许的皮肤域名白名单
yggdrasil.identity_falsificationbool是否允许伪造身份验证
yggdrasil.emailobject可选，SMTP 邮箱配置，用于注册验证

见：账号管理。
